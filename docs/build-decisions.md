# Build Decisions

Rule for the build: follow the approved proposal and slides. Where the proposal answers a question,
we follow it and cite the page. We decide ourselves only where the proposal contradicts itself or
says nothing.

| 28 | Tier-1 rule details, so each rule stays fair: "Sponsored/Advertorial/Promoted" counts only at the **start of the title** or the **start of the category** (so "Officers promoted…" is news; "Promoted Stories" is a paid post). | 32 | **Web-search second opinion.** GPT-4o (no web access) scores every article. When it says Misinformation and the article is not satire, the article stays Pending and **Search GPT** (RapidAPI, with a `web_search` tool) checks it on the web; its score and reason replace the first ones. The first prompt also returns `"satire": true/false`, so satire sources do not use web checks. At most 2 web checks per hourly run; only the 10 newest may wait, older ones get the first verdict (no pile-up). Every web check is logged as "Second opinion" with both scores and the tokens used. Switched off when `SEARCH_API_URL` is empty. Reason: a real P.M. News story about Charlie Kirk's widow scored 10 because the model's knowledge ends before his death; Search GPT found the reports and scored it 88. A web check costs ~14,000–35,000 tokens, so checking every article would need the $75 plan; checking only Misinformation verdicts fits a small plan. **Outcome:** switched off on 11 November 2026 (`SEARCH_API_URL` set to empty on the server) because the provider failed every request for 10 hours (HTTP 400, even its own playground example). The code stays and can be switched back on; until then GPT-4o's verdict is final and the admin corrects real recent events by re-flagging (FR-3.3). | Slide 8 ("tiered"); §2.5.1 (p. 28); §3.5 (p. 38) RapidAPI; NFR-2.1 (p. 32); FR-3.5 (p. 31); `docs/live-site-results.md` |

## To remember during the build

- Automatic admin session timeout. NFR-1.2 (p. 32)
- API key stored outside the public web root. §3.8 (p. 42)
- cURL timeouts so a slow feed or AI reply cannot hang the run. §1.6 (p. 5)
- Log per-source ingestion time as evidence for NFR-4.1 (p. 32).
- Report notes: PDO/MySQLi wording in NFR-1.1; the AI score is the model's own estimate, not a measured probability; recent events cannot be checked (no web access); the AI can be wrong (hallucination risk, slide 6 and §2.3), stated in Limitations, not on screen; the §1.2/§3.1.2 vs NFR-2.1 wording on Pending articles; summary-only input can mislead the AI (decision 29).
