TrustFeed mockup

Built on Start Bootstrap “Blog Home” (public site) and “SB Admin” (admin panel). Everything is clickable; sample articles and scores come from the real RapidAPI tests.

Public site Blog Home template

  • News feedFeatured article, cards with credibility badges, working search, category filter and pagination.FR-2.1, FR-2.2, FR-2.3, NFR-3.2
  • Article detailsSummary, credibility result box, link to the original story; each visit adds a view.FR-2.2, FR-2.4, NFR-2.1

Admin panel SB Admin template

  • LoginSign in with admin / admin123. Admin pages send you here if you are not signed in.FR-3.1, NFR-1.2
  • DashboardTotals, real vs fake ratio, feed statuses and views, all calculated from the data.FR-3.4
  • RSS sourcesAdd (with validation), edit, enable or disable, delete with its articles.FR-3.2
  • ArticlesLive search, re-flag, delete, pagination. Changes show on the public site.FR-3.3
  • System logsExecution runs, API timeouts, failed feeds.FR-3.5

Every page has a yellow bar at the bottom for jumping between screens, hiding the purple proposal references and resetting the sample data. Changes you make are kept in this browser only. Viral Today, Naija Truth Daily, Lagos Wire and Metro Pulse are invented test sources; feed URLs for real outlets still need checking.
